# 校园饭搭子组局与推荐系统

数据库系统课程设计项目，目前处于选题和需求规划阶段。

## 项目构想

面向校园用户，提供饭局发布、查询、报名与退出功能，记录食堂、档口、就餐时间和口味偏好。

## 拟实现功能

- 用户注册、登录和退出
- 饭局发布、查询、修改、删除或取消
- 报名人数控制和个人参与记录统计
- 基于口味、档口和时段的饭局推荐
- 按星期和小时展示平台饭局数量的热力图

## 数据库初步规划

拟设计用户、食堂、档口、饭局、报名记录、口味标签、用户偏好、饭局标签、档口收藏和饭局评价等 10 张表。具体结构将在需求分析与概念设计后确定。

## 当前状态

项目尚未实现。后续将开展需求分析、数据库设计、应用开发和测试。
