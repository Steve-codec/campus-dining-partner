# 校园饭搭子组局与推荐系统

数据库系统课程设计项目，已完成数据库设计、SQL 脚本和独立 MySQL 实例运行验证。

## 项目构想

面向校园用户，提供饭局发布、查询、报名与退出功能，记录食堂、档口、就餐时间和口味偏好。

## 拟实现功能

- 用户注册、登录和退出
- 饭局发布、查询、修改、删除或取消
- 报名人数控制和个人参与记录统计
- 基于口味、档口和时段的饭局推荐
- 按星期和小时展示平台饭局数量的热力图

## 数据库规划

已确定用户、食堂、档口、饭局、报名记录、口味标签、用户口味偏好、饭局标签、档口收藏和饭局评价十张表的实现规格，包含 39 个字段、12 组外键、13 项 CHECK、9 个普通索引和 1 个发起人自动报名触发器。
